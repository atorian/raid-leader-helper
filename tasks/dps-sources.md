# Совместимость источников DPS

При загрузке сохраняется совместимый ручной выбор. Если выбор отсутствует или несовместим, порядок: Details → Skada → Recount → ErrorDPSCounter. Заглушка пишет в штатный Debug на действиях сбора DPS и не создаёт результаты. Сохранённые результаты наград не удаляются.

## Проверенные требования

- **Skada-WoTLK: 1.8.73, ревизия 361 и новее.** В [коммите переработки API](https://github.com/bkader/Skada-WoTLK/commit/d8d1fb4b1f6936fec64a57b8de8578d289aeb2e3) появился `actorPrototype:GetDPS`. Снимок тега 1.8.73.360 этого метода ещё не имеет; 1.8.73.361 имеет. У старых пакетов версия `1.8.73` и ревизия записаны отдельно в TOC (`Version`, `X-Revision`). Проверяются также RegisterCallback и UnregisterCallback. Локальная версия 1.8.78 подходит.
- **Recount: проверенный минимум поддержки r1127.** [Архив автора для 3.3.5](https://www.curseforge.com/wow/addons/recount/files/456867) и [исходники r1127](https://github.com/guldo77/Recount-AddonsCustom-3.3.5) подтверждают LeaveCombat, MergedPetDamageDPS, db2.combatants и переход CurrentFightData → LastFightData с увеличением FightNum. Это проверенный минимум поддержки RLHelper, а не установленная первая историческая ревизия появления API: старый SVN-архив недоступен без авторизации. Исторические обозначения v3.3[a-h] принимаются при наличии всех нужных методов и структуры данных. [Распространённый порт v4.0.1](https://github.com/cornernote/wow-3.3.5-addons/tree/master/Recount) принимается только с Interface 30300. Версия часто находится в X-Curse-Packaged-Version, без обычного поля Version.
- **Details-WotLK: API 140 и новее.** [Исходники порта](https://github.com/Bunny67/Details-WotLK) и установленная сборка v8.3.0.7269 содержат APIVersion 140, CreateEventListener, COMBAT_PLAYER_LEAVE/ENTER, DETAILS_DATA_RESET и методы сегмента. Проверяется API текущего сегмента. DPS рассчитывается как суммарный урон с питомцами / длительность сегмента; спеки фиксируются при подтверждении победы.

## Зависимости и проверка в клиенте

Details, Skada и Recount перечислены в OptionalDeps; DBM-Core остаётся обязательным. TOC задаёт порядок загрузки, но не ограничения версий опциональных зависимостей. Минимальные версии указаны в Notes-ruRU и под выбором DPS; совместимость и красные пункты проверяет RLHelper.

Ширина строки и подсказки вычисляется из scroll viewport при открытии настроек. До показа категории её ширина может быть нулевой; временно используется документированная ширина 375. Скриншот пользователя 2026-10-10 подтвердил обрезание при первоначальном расчёте; расчёт перенесён в обновление OnShow, добавлена проверка нулевой ширины. Повторное отображение после исправления в клиенте пока не подтверждено: computer-use отклоняет WSL sandboxCwd. Для новых метаданных TOC нужен полный перезапуск клиента; для повторной проверки правки Lua достаточно /reload.
