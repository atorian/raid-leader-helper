# Совместимость источников DPS

При загрузке сохраняется совместимый ручной выбор. Если выбор отсутствует или несовместим, порядок: Details → Skada → Recount → ErrorDPSCounter. Заглушка пишет в штатный Debug на действиях сбора DPS и не создаёт результаты. Сохранённые результаты наград не удаляются.

## Проверенные требования

- **Skada-WoTLK: 1.8.73, ревизия 361 и новее.** В [коммите переработки API](https://github.com/bkader/Skada-WoTLK/commit/d8d1fb4b1f6936fec64a57b8de8578d289aeb2e3) появился `actorPrototype:GetDPS`. Снимок тега 1.8.73.360 этого метода ещё не имеет; 1.8.73.361 имеет. У старых пакетов версия `1.8.73` и ревизия записаны отдельно в TOC (`Version`, `X-Revision`). Проверяются также RegisterCallback и UnregisterCallback. Локальная версия 1.8.78 подходит.
- **Recount: проверенный минимум поддержки r1127.** [Архив автора для 3.3.5](https://www.curseforge.com/wow/addons/recount/files/456867) и [исходники r1127](https://github.com/guldo77/Recount-AddonsCustom-3.3.5) подтверждают LeaveCombat, MergedPetDamageDPS, db2.combatants и переход CurrentFightData → LastFightData с увеличением FightNum. Это проверенный минимум поддержки RLHelper, а не установленная первая историческая ревизия появления API: старый SVN-архив недоступен без авторизации. Исторические обозначения v3.3[a-h] принимаются при наличии всех нужных методов и структуры данных. [Распространённый порт v4.0.1](https://github.com/cornernote/wow-3.3.5-addons/tree/master/Recount) принимается только с Interface 30300. Версия часто находится в X-Curse-Packaged-Version, без обычного поля Version.
- **Details-WotLK: API 140 и новее.** [Исходники порта](https://github.com/Bunny67/Details-WotLK) и установленная сборка v8.3.0.7269 содержат APIVersion 140, CreateEventListener, COMBAT_PLAYER_LEAVE/ENTER, DETAILS_DATA_RESET и методы сегмента. Проверяется API текущего сегмента. DPS рассчитывается как суммарный урон с питомцами / длительность сегмента; спек определяется по навыкам в победном сегменте.

## Зависимости и проверка в клиенте

Details, Skada и Recount перечислены в OptionalDeps; DBM-Core остаётся обязательным. TOC задаёт порядок загрузки, но не ограничения версий опциональных зависимостей. Минимальные версии указаны в Notes-ruRU и под выбором DPS; совместимость и красные пункты проверяет RLHelper.

Ширина строки и подсказки вычисляется из scroll viewport при открытии настроек. До показа категории её ширина может быть нулевой; временно используется документированная ширина 375. Скриншот пользователя 2026-10-10 подтвердил обрезание при первоначальном расчёте; расчёт перенесён в обновление OnShow, добавлена проверка нулевой ширины. Повторное отображение после исправления в клиенте пока не подтверждено: computer-use отклоняет WSL sandboxCwd. Для новых метаданных TOC нужен полный перезапуск клиента; для повторной проверки правки Lua достаточно /reload.

## Единственный способ определения спека

Спек определяется только по совокупности атак и исцелений самого игрока из сегмента победного боя выбранного DPS-метра. Пользователь выбрал один способ 2026-10-10; инспект, поле спека актора и ручной выбор исключены:

- Recount: `Fights.LastFightData.Attacks` и `Heals`, ключи — локализованные имена способностей. Структура проверена в [Tracker.lua r1127](https://github.com/guldo77/Recount-AddonsCustom-3.3.5/blob/main/Tracker.lua). Не использовать `OverallData` и атаки питомцев.
- Skada: `damagespells[*].id`, имена записей и числовые ключи `healspells`. Отдельные акторы с классом `PET` исключены из списка игроков.
- Details: `GetSpellList()` акторов урона и исцеления того же игрока в текущем сегменте.

Поле спека актора не участвует в определении. Признаки разных спеков оставляют результат неопределённым. Уникальные способности и повторяемые комбинации обычных навыков участвуют в одном распознавателе; отсутствие навыка без положительной ротации не подходит. Все добавленные ID проверены 2026-10-10 по `https://wotlk.ezhead.org/?spell=ID`; локализованное имя базового ранга позволяет распознавать остальные ранги:

| ДК | 55050 → 250; 49143 / 49184 → 251; 55090 → 252 |

[50590](https://wotlk.ezhead.org/?spell=50590) требует Метаморфозу, но русское имя «Испепеление» совпадает с обычным заклинанием и уроном инфернала. Поэтому определять демонолога по этому имени отдельно в Recount нельзя; комбинация его ротации проверяется независимо.

Неопределённые участники сохраняются поимённо вместе с классом/DPS и видны в окне начисления. Для определённого спека сохраняется планка на момент боя; изменённые позже настройки не подменяют её. Неизвестный спек или отсутствующий DPS не разрешает начисление. Старые сохранённые снимки, из которых участники уже были удалены, не содержат их имён и не могут восстановить список: исправление применяется к новым замерам.

## Комбинации ротаций

Добавлены 2026-10-10 после уточнения пользователя. Пользователь сообщил, что замерные бои обычно длятся от полутора минут: 90 секунд — типичный ориентир, а не обязательная минимальная длительность. Проверки охватывают замеры на 90 и 89 секунд, длинный бой на 180 секунд и границу защиты отрицательных признаков на 29/30 секундах. Это эвристики поведения, а не доказательство распределения талантов. ID ниже проверены по Isengard Database; выбранные количественные границы — правила RLHelper, которые ещё не проверены на реальных рейдовых замерах.

- Кошка: хотя бы два из 5221 (Полоснуть), 1822 (Глубокая рана), 1079 (Разорвать), 22568 (Свирепый укус), 33876 (Увечье — кошка). Медведь: хотя бы два из 6807 (Трепка), 33745 (Растерзать), 33878 (Увечье — медведь), 779 (Размах — медведь). Для каждого зачтённого навыка нужно хотя бы два события; суммарных событий выбранной формы должно быть хотя бы втрое больше событий другой формы. Одно случайное действие другой формы допустимо, равноценное смешение форм не определяет роль.
- БМ: повторяемые 3044 (Чародейский выстрел), 56641 (Верный выстрел), 1978 (Укус змеи), без 53209 (Выстрел химеры) и 53301 (Разрывной выстрел). Одного обычного выстрела или отсутствия Химеры недостаточно.
- Демонолог: повторяемые 686 (Стрела Тьмы), 29722 (Испепеление), 6353 (Ожог души), без 30108, 48181, 50796, 17962 — характерных способностей Колдовства/Разрушения.
- Маг: Тайная магия — 30451 + 5143; Огонь — 133 + 11366 или 44614 + 11366; Лёд — 116 + 30455. Проверяются исключающие талантовые навыки и повторяемые признаки других ротаций. Разовая Ледяная стрела не отвергает Тайную магию; Огненная глыба сама по себе не доказывает Огонь.

Комбинации с отрицательными признаками требуют длительности сегмента не менее 30 секунд и минимум трёх событий каждого положительного навыка. Для обычных исключающих навыков учитывается повторяемость (три события), для характерных талантовых — любое появление. Периодические тики и промахи входят в счётчик: Recount/Skada используют `count`, Details — `counter`. Это не число применений; нельзя автоматически называть три тика тремя кастами. Ранги одного имени объединяются; необязательный счётчик кастов Skada не требуется.

Дубовая кожа (22812) не участвует: проверенный Recount r1127 не записывает обычные усиления в `Attacks`/`Heals`, а `SpellAuraApplied` занимается щитами. Отсутствие записи такого усиления не доказывает отсутствие его применения. Одинаковые нестандартные ротации разных билдов или неполный сбор метра могут дать ошибочную эвристику; неизвестные/смешанные результаты остаются видимыми без инспекта и ручного выбора. Проверки на синтетических данных охватывают одинаковые ротации в Recount, Skada, Details, разовые отклонения, исключающие навыки, смешение форм и короткие сегменты.
