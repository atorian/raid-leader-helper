# Релиз RLHelper 0.5.2

Изменения после версии 0.5.1 для WoW 3.3.5a.

## Что нового

- На героической Синдрагосе журнал показывает взрывы «Освобожденной магии» и число стаков Неустойчивости. Взрыв при трёх и более стаках отмечается как ошибка тактики.
- При переходе Синдрагосы в воздушную фазу показания Skada, Details и Recount разделяются по фазам.

## Что исправлено

- Длинные записи журнала теперь переносятся на следующую строку.

После обновления полностью перезапустите WoW 3.3.5a.
