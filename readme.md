# RL Helper

Аддон для World of Warcraft 3.3.5a, помогающий рейд лидерам управлять рейдом.

Разработка и дебаг ведется на EzWOW и возможно какие-то правила не будут рабоать на других серверах. 
Что-то не работает как ожидалось или есть идеи - чирканите в [Issues](https://github.com/atorian/raid-leader-helper/issues).

## Зачем?

Чтобы эффективно проходить рейды нужно четко выполнять тактику. Бывает что игроки косячат, а бывает что намеренно руинят рейды, портя жизнь другим. Этот аддон нужен тем, кто не хочет тратить много времени на поиск проблемы.

## Возможности

- Визуальный лог текущего боя который не пропадет вместе с сообщениями в чате
- Отслеживание напулов
- Отслеживание нарушений тактики (взывы духов, несоблюдение дистанции, фридомы, диспелы, БР и тп)
- Быстры доступ к кнопкам РЧ, Пула и Отмены
- Быстры доступ к кнопкам ГП

## Установка

1. [Скачайте аддон](https://github.com/atorian/raid-leader-helper/releases)
2. Распакуйте в папку `World of Warcraft/Interface/AddOns`
3. Перезапустите игру

## Использование

- `/rlh` - показать/скрыть главное окно
- `/rlh help` - показать список команд

### Структурированная история V2

Включение: `/rlh journal v2`, затем `/reload` между боями. Возврат:
`/rlh journal v1`, затем `/reload`. По умолчанию включена старая версия.
Выбор применяется при загрузке, поэтому смена настройки не разрывает текущий бой.

- V1 читает и пишет только `db.char.combatHistory`; V2 — только
  `db.char.combatHistoryV2`. Истории независимы, конвертации и параллельной записи нет.
  `/rlh clear` очищает только выбранную историю.
- V2 сохраняет до 30 завершённых боёв, до 20 000 событий в каждом.
  При достижении лимита событий журнал показывает предупреждение о неполных данных.
- Категория записи `type`: `INFO` или `TACTIC_VIOLATION`. Нарушения выделяются
  красным и пометкой «НАРУШЕНИЕ». `kind` описывает смысл события для аддона:
  например, `TAUNT`, `DISPEL`, `FIRST_DAMAGE`, `MISDIRECTION_DAMAGE`.
- Таунт участника рейда вне списка назначенных основных танков (`MAINTANK`)
  отмечается как нарушение. Если основных танков не назначили или источник
  неизвестен, таунт остаётся информацией. Это общее правило рейда, не проверка
  индивидуальных назначений танков на конкретную цель.
- «Все» скрывает попадания напула; «Напулы» показывает начало, каждое попадание
  и итог; «Ошибки» показывает нарушения тактики, отслеживаемые смерти от механик
  Халиона и сводки по духам Леди, газу и гадости Профессора, включая записи `INFO`.
  При наведении на итог напула доступны цели и суммарный урон по каждой.
  Сбор и сохранение не зависят от выбранного фильтра или видимости окна.
- Напулы охотников и разбойников связываются по GUID и `pullId`. Итог показывает
  **урон**, а не рассчитанную переданную угрозу. Для Халиона причина смерти
  определяется по последним попаданиям, как в старой версии.

Запись V2 содержит `seq`, исходный `timestamp`, `type`, `kind`, обычный `text`,
необязательные `source`/`target` (`guid`, `name`, `class`), `spellId`, `amount`,
`missType`, `extraSpellId`, `pullId`. Класс сохраняется, если участник доступен
через игровые unit ID в момент записи. Для итогов, создаваемых аддоном,
используется `time()`. Одинаковые timestamp не объединяют записи.
Цвета и иконки добавляются при отображении; старые текстовые записи не разбираются.

## Системные требования

- World of Warcraft 3.3.5a
- Аддон DBM v4
- Права рейд лидера для использования

## Разработка

Аддон использует:
- Lua 5.1
- Ace3 Framework
- WoW API
